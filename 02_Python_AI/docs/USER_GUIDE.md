# User Guide

1. Install: `pip install -r requirements.txt`
2. Run everything: `python main.py`
3. Explore interactively: `streamlit run app_streamlit.py`
4. Find outputs:
   - Dashboard tables → `powerbi/`
   - Word + Excel report → `reports/`
   - Charts → `plots/`
   - ML metrics → `models/ml_metrics.json`
5. Ask the agent (in the Streamlit "AI Chat" page or via code):
   - "What is today's portfolio health?"
   - "Which vintage is performing worst?"
   - "Explain ECL."
   - "Generate investor summary."
